## Code and inline syntax

The following function accepts a sequence of timestamps in milliseconds and keeps the times at or after a cutoff. The deliberately long comment lets readers verify that the code block scrolls in its own container.

```python
def after_cutoff(timestamps_ms: list[int], cutoff_ms: int) -> list[int]:
    # The cutoff is inclusive so a timestamp exactly on the boundary belongs to the returned sequence.
    return [timestamp for timestamp in timestamps_ms if timestamp >= cutoff_ms]
```

Use `cutoff_ms` to express the boundary in the same unit as the input.
